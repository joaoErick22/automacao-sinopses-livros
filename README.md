# 🐍 Automação de Sinopses de Livros

Automação em Python para gerar sinopses de livros usando APIs, Requests, Pandas e Excel.

### 🛠️ Tecnologias
`Python` `Pandas` `Requests` `Excel` `APIs`

### ✨ O que faz
- Busca dados via API
- Organiza em planilha Excel com Pandas
- Gera sinopses automaticamente

### ▶️ Como rodar
```bash
pip install pandas requests
python main.py
